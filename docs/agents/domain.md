# Domain docs

Rill is a single-context repository.

Before exploring or changing the system, read `CONTEXT.md` and any relevant
records beneath `docs/adr/`. Missing ADRs are not an error; create them only
when an architectural decision needs durable documentation.

Use the glossary's defined vocabulary in issue titles, implementation plans,
tests, and documentation. Avoid synonyms that the glossary explicitly rejects.

If proposed work contradicts an existing ADR, surface that conflict rather than
silently overriding the decision.
